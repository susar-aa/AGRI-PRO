IMPORTANT DEVELOPMENT RULE
==================================================

Do not immediately generate the entire system in one step.

Develop the application in controlled stages.

Before implementing a stage:

1. Inspect the existing project structure.
2. Inspect the current database.
3. Identify existing functionality.
4. Do not overwrite working functionality.
5. Reuse existing components.
6. Identify dependencies.
7. Create a plan.
8. Implement the stage.
9. Test the implementation.
10. Fix errors.
11. Verify database integrity.
12. Verify accounting entries.
13. Verify UI responsiveness.

For every accounting feature, test the complete flow:

Transaction
→ Operational Record
→ Accounting Journal
→ General Ledger
→ Trial Balance
→ Profit & Loss / Balance Sheet

For every inventory feature:

Purchase
→ Stock In
→ Stock Ledger
→ Production / Sale
→ Stock Out
→ COGS
→ Inventory Valuation

Never create fake balances.

Never calculate financial reports from isolated module totals if the data should come from accounting.

Use the central accounting ledger as the source of truth.
